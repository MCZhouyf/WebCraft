# W6 EXT independent-mechanism diagnostic set

**Registered:** 2026-10-17, before any evaluated EXT pipeline episode.

## Status and scope

EXT is a post-review diagnostic addition. It uses explicit extension diagnostic packages, is reported in a separate table, is not merged into the frozen Core42/main matrix, and does not alter any previously reported number. The run is deterministic and makes zero LLM calls.

The author's W6 instruction activates only the candidates that the earlier preregistered authenticity audit classified as `behaviorally_real`. The 57 W5 screening families still marked `pass_pending_author_confirmation` are not treated as confirmed and are excluded. The activated mechanisms are:

1. `recipe:iron_ingot`
2. `recipe:gold_ingot`
3. `recipe:raw_iron_block`
4. `recipe:raw_gold_block`

Their source is `reports/expansion_probe/mechanism_authenticity.csv`; the other 28 audited new mechanisms were classified as representational differences and remain excluded.

## Metrics

All metrics are reported per independent mechanism and method; the aggregate table is descriptive only.

- `SR`: frozen terminal success definition.
- `feasible_SR`: SR restricted to truly feasible task-world instances.
- `overconservative`: truly feasible and reported infeasible.
- `execution_failure`: truly feasible, reported feasible, goal not attained.
- `plan_acceptance_stale_any`: existing non-probe stale-plan acceptance (`HTR_commit`) over all used mechanisms.
- `plan_acceptance_independent`: the same rule restricted to the task's preregistered independent conflict ID.
- `stale_specific_query_exposure`: retrieved/compiled evidence includes the task's independent conflict ID while it is false in the execution world.
- `stale_specific_execution_exposure`: an executed semantic action uses that stale independent conflict ID.
- Real cost: semantic action count, primary semantic cost, probe count, probe cost, and search calls.

## Decision rule

For each independent mechanism and each method separately:

1. Compare `mismatched_old2new` with `matched_1.21.11`.
2. Compare `mismatched_new2old` with `matched_1.16.5`.
3. A strictly positive difference in `plan_acceptance_independent` is reported as mismatch raising plan-level acceptance for that mechanism outside MC1; zero or a negative difference is reported as no observed increase.

No mechanisms are pooled into a single confirmatory number. Results are descriptive because each mechanism is represented by one isolated diagnostic task. Every result is retained regardless of direction; task/package/rule changes after seeing results are prohibited.

## Optional external rows
