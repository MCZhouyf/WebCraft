## 1. Metric-level reproduction gate

Using the anonymous release package code/data and the locked runtime, rerun the
374 main task-condition instances for every executable method in each of
`llm_only`, `all_public`, and `oracle_reading` (11,220 episodes). Compare each
episode to the frozen export by `(reading_mode, method, condition, world,
task_id)`.

The required fields are terminal class, SR, overconservatism among feasible
instances, execution failure among feasible instances, plan-level stale
acceptance, all stale contact, discriminative stale contact in queries and
actions, semantic-action count, semantic cost, and search-call count. Boolean
and integer values require exact equality; serialized numeric costs require
exact `Decimal(str(value))` equality. The terminal classes use the registered
mutually exclusive priority in the frozen evaluator. Stale/discriminative
contact uses the registered measurement-v3 classifier rather than a new text
heuristic.

For episodes whose normalized semantic action sequence differs while every
required metric agrees, assign one exclusive reason in this order:

1. `equivalent_resource_node`: only interchangeable resource-node parameters
   differ, with equal observed output and cost;
2. `dependency_equivalent_tie`: mechanism multisets agree and the differing
   order is a topological permutation of independent prerequisites;
3. `other`.

Report metric mismatches by method and reading mode and action-only differences
by reason. The reproduction statement is selected mechanically: zero metric
mismatches gives "全部报告指标逐实例复现，动作顺序在依赖等价处可能不同";
nonzero mismatches gives "存在指标差异（列出）" unless the observed evidence
requires a more precise third formulation.

## 2. Semantic-equivalence O gate and decomposition

This forward-looking amendment is registered after the W7b exact-order O gate
failed and before any accepted V/C/V+C result exists. For the four W7b cells
(T1-to-1.21.11 mismatch and its T3 match; T3-to-1.16.5 mismatch and its T1
match), O passes per episode iff terminal, semantic cost, mechanism multiset,
and every metric listed in section 1 equal the frozen export. Action order is
not part of this gate. Any O failure stops this component before intervention
effects are accepted.

After O passes, reuse the W7b V, C, and V+C definitions byte-for-byte:

- V replaces a target-world-stale claim payload with target-world truth in the
  same hit/timestamp/position, retaining and counting claims with no valid
  counterpart;
- C appends target truth, generated directly from truth files, only for an
  oracle-path relation missing from O while retaining stale claims;
- V+C applies V and then C.

No template-gold inventory is used. For SR, overconservatism, execution
failure, and plan-level acceptance, report intervention minus O as `dV`, `dC`,
`dVC`, and `interaction = (V+C)-V-C+O`, with task-paired intervals. The frozen
11.7647 pp Naive old-to-new gap is discussed using dV and dC beside dVC and
the interaction; nonlinear effects are not forced to add to 100%.

Read the accepted W7b CP-RAG runs and the exactly matched Naive rows for main

`other`.

## 4. Symmetric pipeline BIA

The registered/original BIA lets only probe-oriented methods consume probe
observations. Add a parallel symmetric score without changing any episode:
every method may consume public observations from every semantic action it
actually executed in that episode. A contradicted claim is invalid, a
confirmed claim is valid, and unresolved candidates retain the method's
registered disposition. Inventory snapshots, public output/error classes, and
the frozen candidate set are the only evidence; truth is used only for final
scoring.

Report original and symmetric BIA for every pipeline and CP-RAG in each CDS
condition. For Naive, Verify-All, ARBITER, and CP-RAG, report every pairwise
difference under each rule and the change in that difference. Denominators are
the same frozen boundary-candidate questions; missing predictions remain
abstentions rather than silently leaving the denominator.

## 5. Numeric-semantics crosswalk

For all DV assertions, produce a cross-tab between assertion type (`name`,
`recipe`, `smelting`, `drop`, `craftability`) and conflict type
(`new_identifier`, `replacement`, `feasibility_change`, `rename`, `removed`,
`always_false_control`). Preserve any source category that cannot be mapped and
stop rather than guessing. Trace the 542-versus-537 name count and recipe
median 7-versus-6 to explicit source filters/rows.

Compare the original combined placebo to the split W7b placebo by identical
episode key. The combined and split terminal counts are not added because they
are separate counterfactual reruns with different simultaneous interventions.
List every episode changed by the combined intervention but unchanged under
both split interventions.
