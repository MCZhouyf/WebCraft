## Two reasoning passes and discrepancies

Pass 1 fixes hypotheses and conservative rules before outcomes: global time
support can propagate across mechanisms only when public evidence actually has
multiple years; local contradictory statements may instead be extraction noise.
Missing corpus facts, missed BM25 hits and compilation gaps are distinct. A
manually exported target-year corpus can be selected toward specific subjects.
Pass 2 tests information isolation, local/single-year degeneration, source-year
support provenance, complete episode accounting and alternative explanations.
Do not tune thresholds to held-out outcomes or reinterpret null effects.

## Policy specification v1 (parameters fixed now, dev8 for implementation only)

Use the same public reader bundles, contract-v2 claims, item normalizer,
compile_claim_assertions, operator_from_assertion and BeliefPlanner as CP-RAG.
Keep shared policy: 90 semantic-cost/action limit, five candidate plans,
uncertainty_weight=.35, inventory-aware, at most 12 explicit probes. Do not
change solver behavior or frozen source. No parameter search is planned.

The runtime runs in a separate process. It receives only public goal item/count,
public kit, public resource types and six-field hits/contract-v2 claims. No task
ID, condition, world, feasible label, conflict catalogue, candidate versions,
probe/version table or truth is passed. Parent evaluator alone loads simulator
truth and task metadata. Runtime filesystem audit guards forbid truth/, data/,
oracle/, reports/, artifacts/, evaluator/, release assets and version registry
files; only its code, standard/shared libraries, public compiler sources and
temporary solver files are permitted. Public RPC calls return only world API
observations; research RPC returns only public hits and claims. No model client.
Do not parse version mentions to construct a version list or mapping.

Epochs are UTC calendar YEARS parsed ONLY from timestamps on observed search
hits. They are not evaluation versions, release epochs or supplied anchors.
Each episode starts uniform log-weight zero over its own retrieved source years;
unknown timestamps have no year. New research may introduce new public years
with log-weight zero. No state persists across episodes/tasks.

For a demanded relation, group compiled operators as CP-RAG does: drop by block,
name by identifier, otherwise (method, output). Distinct structural payloads
define a conflict. Use CP-style first planned dependency, with a cheapest
currently executable action among that relation's compiled candidates as the
probe (semantic cost; ties method, canonical resolved params, mechanism ID).
Only actions whose candidate predictions/feasibility can differ are eligible;
do not invent missing ingredients or absent name operators. If the shared
compiler cannot represent a requested action/fact, report that limitation.
There is no extra designer-supplied separator or probe/version lookup.

After every semantic observation (probe or ordinary execution), compare it to
the attempted candidate(s). Mine observations can adjudicate all same-block
drop candidates by actual item IDs/counts. Recipe/smelt candidates are evaluated
only when their resolved public action params match the attempted action;
successful alternative layouts do not falsify untried layouts. Name candidates
require an actual boolean resolvable response. Resource/interface failures
(missing inputs/fuel/tools, depleted/unknown nodes, unavailable station, generic
error) give no temporal or semantic evidence. No truth-based inference.

An informative observation updates each distinct (year, source_site) once:
sign +1 for matching positive payload / contradicted negative payload, -1 for
the reverse; mixed support from that same source-year cancels to zero. Average
these signs over sources within each year, then add log(3) times that average
to the year's log-weight. Clip each weight to [-20,20]. Do not multiply evidence
by duplicate claims. Track latest local confirmed/refuted mechanism separately.

Belief is formed only if at least two years have been retrieved, an observation
has given a nonzero contrast between years, top posterior >= .80 and its odds
relative to the runner-up >= 3. Otherwise use Naive's latest-timestamp rule
per mechanism and CP-style local feedback. Ties use newest year only for a
deterministic reported estimate; a tied posterior is not formed belief.

When formed, globally retain only claims whose source year equals the top year,
including single-sided relations; unknown-year claims are missing. Compile the
retained claims without changing their payload. Observed local refutations
remain blocked; a local positive observation does not restore an unavailable
relation outside the temporal filter. Empty relation means missing, not false.
If no plan remains after denial/filtering, requery the denied/filtered relation
and goal once per relation, CP-style query "subject goal", k=10. Direct-gold/CDS
have no corresponding live index: their supplied public bundle is the closed
research space, no extra facts are supplied. Count actual additional searches.
Failure exhausts current knowledge: submit infeasible; budget exhaustion submits
unknown. Missing or ambiguous years mean unformed belief, not a guessed world.

## Retrieval/compiler ceiling (existing 203 failed re-search invocations)

Use W10 reconstructed query export; select executed_search_inferred=1, no cache
reuse, not no_public_index. These are code/trace-inferred searches, NOT verbatim
request telemetry. If resulting N differs from 203, report actual N and why.
Target relation is denied claim's subject and mechanism family (not arbitrary
goal facts). Scan ALL frozen documents, not only top-10. Detect positive payloads
in the mode's public claims cache; evaluate whether they match target-world
truth ONLY in this offline evaluator. In addition locate textual cooccurrence
of normalized subject/ingredient/drop names with mechanism keywords and quote
short spans. Text cooccurrence alone is a candidate, NOT proof of a true fact;
without a defensible payload/support match mark textual existence unresolved.

Registered categories: corpus_absent_confirmed only when full corpus and cache
offer no supporting explicit payload/text; exists_bm25_missed if an evaluator-
confirmed valid public fact exists but its chunk is absent at k=10;
retrieved_uncompilable if valid fact is at k=10 but cannot compile to its target
candidate. Report existing_compilable_but_not_novel/other separately: a logged
zero NEW candidates does not imply retrieval failure. Unknown/unassessable text
is unresolved, not forced into the requested three categories. For each valid
fact compute first rank among all positive BM25 scores (minimum k); zero-score
valid chunks are unretrievable under this backend, even at corpus-size k.
Give category counts, uncertainty and up to 3-4 real examples per nonempty
category. Do not fabricate examples for an empty category.
