# A21 rate denominators before formal results

Registered before any formal model episode. SR point estimates use all
registered episodes of that condition; feasible-task SR uses all truly
feasible episodes, including families with different numbers of feasible
directed cells. Feasible SR is not the unweighted mean of family-specific
rates. Uncertainty resamples the eight mechanism families (10,000 draws,
20261018), retaining every instance in each sampled family. Paired contrasts
retain all instance pairs of each sampled family and recalculate the same
pooled rate difference. This makes reported K feasible SR use the same
denominator as its gate. No formal point estimate or interval exists yet.
