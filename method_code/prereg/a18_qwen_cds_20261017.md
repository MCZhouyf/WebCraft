## Concurrency and stopping

At most **two** simultaneous requests to the local endpoint, including canaries
and retries. Independent GLM gateway work can run alongside it under its own
limits. CPU clients use nice 15, single-threaded numerical libraries, disabled
CUDA, and the author's effective-memory gate of 1.8 GiB. Record client peak RSS
only; do not inspect or manipulate model-service processes.

Use one preflight canary per worker and the existing exact JSON inventory
canary every 200 task attempts. Require the committed exact model identifier
on **every** successful response. Any wrong, missing, or second identifier
stops the entire A18 segment immediately. Queue-timeout response or request
timeout also stops immediately. Three consecutive transport/service errors
across workers stop the segment; a valid response resets that counter.
At most two byte-identical retries of other transport/service failures, with
10-second waits; refusals and malformed model answers retain A8 terminal
treatment, never trigger a model swap or episode replacement. A failed canary
stops execution. Fixed connect/read timeout and queue-error recognition are
committed in the transport lock before release. Log sanitized error types and
HTTP codes, never exception strings containing addresses or credentials.
