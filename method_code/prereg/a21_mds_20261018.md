# A21: medium-depth mechanism suite

Registered before any A21 model request. This is post-review IV and does not
alter any frozen result, task, prompt, scorer, or WebCraft file.

## Purpose and scope

MDS fills the gap between the one-action-median CDS and the held-out matrix.
It contains 32 directed instances from eight held-out EXT-v2 mechanism
families: `blue_carpet`, `iron_ingot`, `chiseled_bookshelf`, `lodestone`,
`oak_chest_boat`, `saddle`, `chain`, and `iron_chain`. Each family contributes
its four already frozen directed world pairs. The statistical cluster is the
eight-family mechanism family, never the 32 instance rows.

Twenty target worlds are feasible and have oracle primary cost 5, 6, 8, 9, or
10. Twelve reverse directed target worlds are genuinely infeasible under the
same task definition; their oracle cost is recorded as `null` and they remain
in SR and stale-contact denominators. No route is supplied for an infeasible
world. The sole explicit non-focal material bypass is one `oak_log` in the
`oak_chest_boat` family, reducing its feasible oracle cost from 11 to 10.

The visible material contains only `{mechanism fact, source, timestamp}`.
Facts are copied from the frozen truth-derived CDS material and augmented by
the evaluator-only target-world oracle path. `K+S` is the corresponding CDS
stale addition, `K+N` its equal-length neutral addition, and `empty` contains
no injected knowledge. Each agent sees facts only through the existing first
`inventory` observation and the existing eight-step ReAct history. The agent
does not read truth files, evaluator material, task feasibility, oracle plans,
comparison-world labels, or a candidate-version list.

## Development gate

Before formal episodes, run ReAct on the eight `split=dev` tasks only under K.
Those materials are separate from MDS and are derived from each development
task's target-world oracle route. The formal suite is eligible only when the
eight-task feasible success rate is in the inclusive interval `[0.40, 0.80]`.
If it is below 0.40, build a separately labelled two-mechanism shortened
variant and rerun this development gate once. If the second gate is below
0.40, stop before reading MDS formal material. A result above 0.80 is reported
as an out-of-range gate and does not authorize formal execution.

## Formal execution and scoring

Run ReAct with `glm-5.2` over four conditions `{K, K+S, K+N, empty}` and all
32 MDS instances, one episode each. Decoding is temperature 0, JSON output,
thinking disabled, at most 40 model calls and 90 semantic action cost. The
history window is eight actions. At most two independently credentialed
workers run concurrently. A queue timeout or three consecutive infrastructure
errors stops the current run and is never counted as a cognitive failure.

The frozen v3-d scorer and target-world conflict catalogue score stale contact
and propagation after the episode. Registered contrasts are `K+S - K+N` for
SR, stale-specific contact (query and action split), and v3-d propagation;
and `empty - K` for SR. Point estimates and 95% intervals use 10,000 paired
family-cluster bootstrap draws with seed `20261018`. K+S versus K additionally
exports the first semantic action divergence; it is descriptive only.
